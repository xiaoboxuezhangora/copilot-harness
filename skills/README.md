# skills

Skill assets for the `copilot-harness` monorepo.

Reusable skill definitions live under `.github/skills/`, which is the directory currently passed
to the Copilot SDK session config.

Migrated skills:

- `blood-transfusion`: APMIS transfusion-chain analysis, including `备改输`, `BIZ857`,
  scene-code dispatch, ODCBS/ODBIP ownership boundaries, async messages, and platform push.
- `angular17-upgrade-regression-handler`: Angular 17 upgrade regression triage and repair
  workflow with baseline attribution, DOM evidence, and historical case references.
- `angular-delivery`: Angular 17 implementation and review conventions for components,
  ng-zorro tables, overlays, and shared UI behavior.
